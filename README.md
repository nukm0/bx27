# Marketplace. — полный исходный проект

## Состав
- Next.js 14 / React / TypeScript.
- Тёмная графитовая тема с фиолетово-розовыми акцентами.
- Выдвижная панель разделов админки с закрытием крестиком, кнопкой назад и свайпом.
- Клиентские экраны пользователей, FAQ, магазинов, баннеров, жалоб, ролей, верификации и журнала действий.
- Клиентские данные сохраняются в localStorage этого браузера.

## Запуск
```bash
npm install
npm run build
npm run dev
```

## Важно
Этот ZIP содержит весь исходный проект, а не один файл `page.tsx`. Полный перечень требований находится в `ТЗ-полный-список.md`.

**Текущая версия не является безопасной production-системой.** Клиентское localStorage не синхронизирует данные между пользователями, а интерфейсные ограничения можно обойти. Реальные Telegram-роли, верификация, баны по ID, наказания, массовые уведомления и единая база магазинов требуют серверной реализации и проверки Telegram `initData` на сервере. Не считайте доступность формы гарантией того, что соответствующее действие уже защищено на сервере.

Полная сборка Next.js для этого архива не подтверждена в текущем окружении. Перед деплоем выполните `npm install` и `npm run build`; при ошибке сохраните полный лог.
